# Let-her-step-out-of-the-screen-and-into-your-world
一个纯静态、零依赖的浏览器端 AR 取景合成工具，基于透视投影实现二次元立绘与视频流的三维对位。移动端核心页面的几何投影由空间姿态数据实时解算俯角与滚转角。相机设于 $y=h$，地面为 $y=0$，二次元立绘置于指定 $(x, z)$ 坐标，其屏幕投影高度与足底贴地位置由透视投影方程计算。支持五档景别、取景框四边吸附逻辑，并在未开启自动旋转时通过姿态接口对 UI 与世界层执行逆向补偿。桌面端则复用投影管线，用于离线图像导入、抠图与参数微调。渲染导出管线基于统一 frameRect() 裁剪。多图层导出时独立渲染带 Alpha 的二次元立绘层
