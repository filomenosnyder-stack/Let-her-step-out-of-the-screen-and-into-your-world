# 让她走出屏幕，走进你的世界

一个纯静态、零依赖的浏览器端 **AR 取景合成工具**。

把二次元立绘按透视投影摆进手机摄像头的实时画面里：相机设于 $y=h$，地面为 $y=0$，
立绘置于指定 $(x, z)$ 坐标，其屏幕投影高度与足底贴地位置由透视投影方程解算；
移动端核心页面的俯角与滚转角由空间姿态数据实时解算。桌面端复用同一条投影管线，
用于离线图像导入、抠图与参数微调。

**在线**：https://filomenosnyder-stack.github.io/Let-her-step-out-of-the-screen-and-into-your-world/

## 一 · 本项目自己的文件

```
index.html        桌面端单页：离线图像导入、抠图、参数微调、导出
cutout.js         AI 抠图（ISNet-anime + onnxruntime-web，纯前端）
phone/index.html  手机端 AR 取景器：摄像头实时对位、投影摆位、按取景框出图
anime/            抠图模型与运行时（isnet-anime-q8.onnx、ort-wasm-simd-threaded.*、ort.min.js）
chars/chars.js    立绘清单（由 tools/scan_chars.mjs 生成，别手改）
chars/多的素材/    工具自带的示例立绘：00_半身1 / 全身1 / 全身2 / 全身3 / 全身4
docs/             以上内容的 Pages 发布目录（这个站的 Pages 从 docs/ 发）
```

**只有上面这些是这个项目的。**
